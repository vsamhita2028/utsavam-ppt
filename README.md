# Utsavam 2026 presentation

A React/Vite presentation for the event. The source content is in `slides.json`; artwork is in `public/assets`.

Run locally with Node.js 18 or newer:

```sh
npm install
npm run dev
```

Open the address Vite prints. Use the arrow keys, space bar, or the on-screen controls to move between slides. Press F or use the fullscreen button for presentation mode. The Download PPTX control saves the accompanying PowerPoint. The `dist` folder is the production build and can be served by a static web server.

Event details and artwork are based on the supplied React Hyderabad website source. The schedule should be checked against the latest event updates before use.
